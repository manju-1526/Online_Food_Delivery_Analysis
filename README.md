# 🍔 Online Food Delivery Analysis Dashboard

An interactive **Online Food Delivery Analysis Dashboard** developed using Python, Pandas, MySQL, SQL, and Power BI.

This project analyzes customer orders, revenue, delivery performance, cancellations, and profitability to identify business trends and support data-driven decisions.

## 📌 Project Overview

The project involves:

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- MySQL Database Storage and SQL Analysis
- Interactive Power BI Dashboard

## 🛠️ Tools and Technologies

- **Python & Pandas** – Data cleaning and analysis
- **Google Colab** – Development environment
- **MySQL & SQL** – Database storage and analysis
- **Power BI** – Dashboard visualization
- **GitHub** – Version control

## 🔄 Project Workflow

1. **Data Cleaning:** Handled missing values and prepared the dataset.
2. **EDA:** Analyzed order values, delivery times, customer preferences, and cancellation patterns.
3. **Feature Engineering:** Created additional features for business analysis.
4. **SQL Analysis:** Stored cleaned data in MySQL and performed analytical queries.
5. **Power BI:** Developed an interactive dashboard to visualize business performance.

## 📊 Power BI Dashboard

### Key Performance Indicators (KPIs)

| KPI | Dashboard Value |
|---|---|
| Total Orders | 100K |
| Total Revenue | 171M |
| Average Order Value | 1.79K |
| Average Delivery Time | 124.98 |
| Average Delivery Rating | 2.99 |
| Cancellation Rate | 15.04 |
| Profit Margin | 15.04% |

### Dashboard Visualizations

- **City-wise Orders:** Order distribution across cities.
- **Cuisine-wise Orders:** Popular cuisine categories.
- **Weekday vs. Weekend:** Comparison of order demand.
- **Distance vs. Delivery Time:** Delivery performance analysis.
- **Interactive Filters:** Filter data by city and order status.
